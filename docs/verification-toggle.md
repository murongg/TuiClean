# 默认折叠与反复展开验证

日期：2026-09-15。版本保持 0.1.0。

## 修改

- 默认模式折叠所有命中项，包括疑似线索与跨账号模板；仅标注仍为显式可选模式。
- 展开、折叠、不再提示分别保存独立状态。展开不再移除提示条，可反复切换；只有不再提示才移除本条提示。
- 白名单、类别开关、无命中内容和现有设置备份格式保留。

## 证据

- 新测试先复现默认不折叠、展开与关闭提示混用等失败。
- 修改后 57 项测试、TypeScript、Chrome/Firefox 构建和格式检查通过。
- Chromium 虚构页面加载时三条模板自动折叠；连续三轮展开后均保留一个提示条和一个折叠按钮，再次折叠成功。浏览器无错误或警告。
- ZIP 完整，版本 0.1.0，页面脚本与验证过的构建产物逐字节一致，权限仍为 storage。

## 应用

重新加载扩展并刷新 X。此前明确选择了仅标注的用户需要切换到默认折叠。当前交互验证基于本地虚构页面，未在更新后的真实 X 页面验证。
