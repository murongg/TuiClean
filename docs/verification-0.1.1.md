# TuiClean 0.1.1 验证记录

日期：2026-09-15。

## 修复

原版本仅逐条匹配文字线索，没有跨账号模板证据。新增当前帖文详情内的模板比较，忽略表情、空白及零宽字符，两个不同账号使用相同较长文字时标注“疑似模板刷屏”，不自动折叠或判定色情。

排除主帖、显式白名单和包含媒体/引用的内容。重复 DOM 或同一作者不会增加独立账号计数。新回复出现和旧回复移除时重新计算证据。

## 验证

- 修改前原有 38 项测试通过。
- 新测试先复现模板不被标注、媒体状态缺失等失败。
- 修改后 `npm run verify`：48 项测试、TypeScript、Chrome 构建均通过。
- `npm run build:firefox`、`npm run zip`、`npm run format:check` 通过。
- ZIP 检查：版本为 0.1.1，包含 spam-template 规则，权限仍仅 storage，压缩包完整。
- 新测试仅使用虚构账号和虚构文案，未把用户截图原文或账号写入测试。

## 限制

目前验证使用合成数据与 DOM 集成测试，尚未获得截图对应帖文链接，未在该真实页面验证。只有同时出现在当前已加载回复中的模板才能相互提供证据，短回复和媒体内容不参与模板检测。
