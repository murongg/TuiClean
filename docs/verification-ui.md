# 紧凑提示 UI 验证记录

版本按用户约定固定为 0.1.0。日期：2026-09-15。

## 修复

实页读取确认 X 的 article 是横向 flex 容器。旧提示作为同级元素占约 385 像素，将正文压至约 133 像素。

新版把未折叠提示放到原文下方，只显示状态、折叠和详情。原因、关闭提示与信任作者放入详情。手动折叠后，展开入口在隐藏内容之外。

## 验证结果

- 53 项测试通过；TypeScript、Chrome 和 Firefox 构建通过。
- 界面静态检测无发现，源码格式检查通过。
- 虚构数据浏览器验收：598 像素容器里原文/提示各 518 像素；320 像素容器里各 240 像素，提示均在原文下方。
- 浅色、深色、详情开关与手动折叠恢复已检查。
- package.json、lockfile、两种 manifest、Chrome ZIP 均确认为 0.1.0；ZIP 内容与构建产物一致。

## 验证边界

修复前读取了真实 X 页面的布局。修复后在相同布局结构的虚构页面完成验收，用户的 X 页面仍显示旧版提示，需要重新加载扩展并刷新页面后完成实页确认。测试中未保存真实帖子、账号或截图。
