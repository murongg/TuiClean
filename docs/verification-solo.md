# 单条引流话术漏判修复

日期：2026-09-15。版本固定 0.1.0。

## 根因

只读检查真实页面确认：用户已打开问题回复的独立详情页，页面仅有上级帖文与当前主帖，没有其他同模板账号。旧的跨账号模板规则排除了主帖，也无法形成重复证据；正文没有命中已有的明确招揽关键词。

## 修改

新增 adult-bait：完整成对的挑逗式比较话术可单条命中，包括独立详情页主帖。把表情与零宽字符清理集中到 lib/text.ts，重复模板与单条话术共用。保留类别开关、规则开关、上下文保护和白名单。

## 验证

- 新增测试先复现普通与混淆文案不命中、独立主帖未折叠。
- 修复后 npm run verify：62 项测试、TypeScript、Chrome 构建通过。
- Firefox 构建、ZIP 打包、格式检查通过。
- 在当前真实主帖的 DOM 文字上执行只读匹配核对，清理后的文案命中新规则。此检查没有修改 X 页面，也没有将真实账号或原文写入测试。
- ZIP 版本为 0.1.0，包含 adult-bait，页面脚本与构建产物一致，权限仍仅 storage。

## 边界

真实页面验证的是新规则的只读匹配结果；更新后扩展的页面折叠效果仍需要重新加载扩展并刷新 X 后确认。识别为疑似引流话术，不据此认定账号身份。当前并未引入跨页面记录或远程识别。
