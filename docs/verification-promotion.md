# 站外引流与昵称招揽验证

版本：0.1.0。日期：2026-09-15。

## 修复

- 补充站外平台、博主/账号推荐与成人描述的组合规则，支持措辞变化、表情和零宽字符。
- 补充昵称中的成人招揽与联系信息组合规则；完整读取被页面拆成多个片段的昵称。
- 保留白名单、分类开关、独立规则开关与上下文保护。默认折叠命中项，展开后仍可再次折叠。
- 识别仍在本地运行，无新增权限。没有访问作者主页或保存页面内容。

## 验证证据

- 先加入虚构正反例和页面解析测试，观察到 11 项失败，再实现修复。
- 完整测试：13 个文件、94 项通过；单元测试只使用合成内容和虚构账号。
- 类型检查、Chrome 生产构建、Firefox 构建、Chrome ZIP 打包与格式检查通过。
- 通过浏览器只读接口读取当前 X 页已渲染内容，在内存中交给由项目源码构建的识别器，使用默认设置核对：6 条站外引流和 2 条昵称招揽命中新增规则。
- 真实页面内容未写入测试、文件或安装包。这里只核对了新识别器的结果；已安装扩展的页面折叠效果需要重新加载扩展并刷新 X 后生效。

## 使用与边界

扩展保持“色情引流”开启、“默认折叠”模式。若扩展从项目的 `.output/chrome-mv3` 加载，在扩展管理页重新加载，然后刷新 X。若从其他解压目录加载，先更新该目录中的安装包内容。

规则属于本地启发式判断，无法保证识别所有改写，也可能误判。普通运动描述、平台名称、联系方式或交友字样本身不触发新增规则；可以在提示条查看依据、单条展开或设置白名单。
