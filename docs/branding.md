# TuiClean 视觉规范

用户选定：黑白灰为主，少量蓝色，简洁克制。Logo 组合当前的 X 标志与扫帚。

## 配色

| 用途           | 颜色    |
| -------------- | ------- |
| 页面底色       | #f7f7f8 |
| 内容表面       | #ffffff |
| 正文与标题     | #191b1f |
| 辅助文字       | #636972 |
| 分隔线         | #e3e5e9 |
| 操作与选中状态 | #2563eb |
| 操作悬停       | #1d4ed8 |
| 选中背景       | #edf3ff |

蓝色集中用于主要操作、开关、选中状态和焦点。标题、普通标签与示例头像使用中性色。错误状态保留独立语义色。

## Logo

白色圆角底，黑色 X 标志的几何中心与底板中心对齐，右下方叠加蓝色扫帚。扫帚的白色边缘使其与 X 笔画保持清晰分界。`public/mark.svg` 是页面 Logo 的唯一素材来源；弹窗、设置和体验页共用它。`public/icons/` 内提供 16、32、48、128 像素 PNG，更新 SVG 后需同步渲染这些尺寸。开发体验页与扩展构建共用 `public` 目录。

X 路径取自 X 官方品牌工具包，保持原图比例。原始来源与素材说明保存在 `public/licenses/x.txt`，随扩展一起打包。

## 验证

主要正文与背景对比度 16.11:1，辅助文字 5.17:1，蓝色主按钮的白色文字 5.17:1，蓝色选中文字在选中背景上 4.64:1。16、32、48、128 像素图标均已渲染，并检查浅色与深色工具栏背景。

本次只调整视觉素材、样式及体验页的公共素材目录，不更改过滤与拉黑逻辑；版本保持 0.1.0。
