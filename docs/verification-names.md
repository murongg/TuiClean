# 昵称招揽漏判修复验证

版本：0.1.0。日期：2026-09-15。

## 原因与修复

旧昵称规则同时要求成人服务表述和联系入口，遗漏了只在显示昵称中明确寻找成人伴侣的账号；正文仅数字也不满足原有重复模板的长度要求。用户名通配符匹配的是 @账号 ID，与显示昵称是不同字段。

- 扩展 adult-profile：明确寻找成人伴侣的昵称可独立识别，无需主页或私信字样，忽略表情、空白及零宽字符，保留否定和科普语境。
- 增加 spam-profile：昵称中的招揽式自称、线下邀约与 1–3 位数字正文同时出现，且没有媒体时，判为疑似广告。各个信号单独出现不命中。
- 沿用默认折叠，支持展开后再次折叠；白名单、分类和独立规则开关继续有效。不会自动执行 X 拉黑。

## 验证

先写合成数据测试，观察到 11 项失败，再实现修复。新增 25 项测试覆盖明确昵称招揽、表情/零宽字符、线下邀约组合、普通活动/教练称呼、实际讨论内容、媒体、科普/否定语境、规则开关及完整页面折叠和恢复流程。未把真实昵称或账号写入测试。

npm run verify：15 个测试文件、159 项通过；类型检查及 Chrome 生产构建通过。Firefox 构建、Chrome ZIP 打包及格式检查通过。测试验证了默认设置下的合成场景，未声称已重新加载用户的扩展或在截图页面上完成折叠。

## 使用

重新加载扩展后刷新 X。明确成人昵称受“色情引流”开关控制；线下邀约与数字回复组合受“垃圾广告”及“昵称线下招揽”规则控制。规则是启发式判断，疑似项可以展开、信任作者或关闭对应规则。
