# 本地拦截历史验证

版本：0.1.0。日期：2026-09-15。

> 以下为最初的历史记录实现验证。当前版本已增加原文快照、4 MB 容量限制及完整备份，现行功能见 [README](../README.md#回看拦截记录)。

## 实现

使用 WXT 的 browser.storage.local，历史独立保存在 tuiclean:history。默认启用，保留最近 1000 条帖文的首次命中记录；只包含帖文编号、@账号、时间、分类、规则、原因及折叠/标注状态。原帖链接按编号与账号生成，不保存全文、显示昵称或正文外链。

后台统一串行写入，设置读取也在队列内，避免先收到的记录在清空后回写。内容页面只能提交记录，扩展页面才能读取和清空；历史写入不触发设置监听重新扫描。控制器记录当前页已见帖文，避免反复扫描重复写入或在清空后立即回填。记录保存失败不恢复被过滤内容。

弹窗和设置均提供“拦截记录”入口，支持分类/规则筛选、原帖链接、信任作者、记录开关与清空。历史独立于设置备份，关闭新增记录会保留已有记录。体验页使用内存适配器，刷新后清空。

## 验证

- 先用合成测试复现缺失行为及清空/写入竞态，再实现修复。
- npm run verify：18 个测试文件、181 项测试通过，类型检查及 Chrome 构建通过。
- npm run build:firefox、npm run zip、npm run format:check 通过。
- Chrome 和 Firefox 清单均保留 storage 权限及 0.1.0 版本，并生成对应后台入口。
- 覆盖元数据投影、去重、1000 条限制、存储失败恢复、记录开关、旧设置兼容、消息来源验证、清空顺序、页面扫描、错误/空状态、筛选及信任作者。
- 实际体验页验证记录显示、筛选后显示 1/3 条、信任作者后的状态更新，以及从弹窗入口进入历史时回到页首。
- 390 px 视口检查通过，内容宽度与视口宽度均为 390 px，没有横向溢出。
- 独立代码与视觉检查未发现需要修复的问题。

## 验证范围

真实 storage.local 调用和后台消息使用模拟浏览器 API 测试；尚未重新加载用户已安装的 Chrome 扩展验证真实页面持久化，也未运行 Firefox 浏览器实测。更新后需重新加载扩展并刷新 X。记录只从启用后的命中项开始，无法恢复此前未保存的历史。
