# 自定义输入测试区验证

版本保持 0.1.0。日期：2026-09-15。

## 功能

体验页新增“自己试一条”：输入正文，可选昵称与账号，查看识别结果、原因和实际折叠预览。连续加入多条可以测试重复模板。HTTP/HTTPS 链接参与域名规则，输入文字按文本渲染，不执行 HTML，也不自动访问链接。

每条最多 20,000 字符，最多 50 条自定义内容。清空、重置和刷新会清除对应输入；切换设置保留未提交草稿。内容和测试偏好仅在本页内存中保留。

## 验证

- 新测试先复现没有输入框、缺少输入解析模块；后续回归先复现切换设置丢失草稿。
- 71 项测试、TypeScript、Chrome/Firefox 构建及格式检查通过。
- 页面和体验页共用 inspectBatch，复用同一套识别与跨账号上下文规则。
- 浏览器实际输入虚构广告后命中并折叠；输入两条不同账号的同模板内容命中重复规则；清空后自定义卡片数为 0。
- 浏览器错误/警告日志为空；390 像素视口的内容宽度为 390，无横向溢出。
- UI 静态检测无发现；Chrome ZIP 与构建产物逐文件一致，版本 0.1.0，权限仍为 storage。

所有自动化与浏览器测试均使用虚构文本与示例账号。
