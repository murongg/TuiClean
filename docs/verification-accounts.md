# 账号拉黑与用户名规则验证

版本：0.1.0。日期：2026-09-15。

## 功能

- 提示条增加本地拉黑、取消本地拉黑与 X 拉黑独立入口。
- 本地黑名单按完整账号保存；用户名规则支持完整匹配和 * 通配符，忽略大小写，不匹配昵称或正文提及。
- 白名单和总开关优先，旧设置及备份继续可用。分类开关不取消用户明确的账号规则。
- 本地拉黑立即折叠同一作者的已加载内容，覆盖以前的单条展开或不再提示状态；仍可再次展开、折叠或取消拉黑。
- X 拉黑由明确点击触发，核对页面、帖文、菜单及确认框中的账号后提交原生操作。规则命中不会自动拉黑 X 账号。
- 设置支持编辑、导入和导出本地黑名单及用户名规则。体验页支持本地流程测试，不操作真实 X 账号。

## 验证结果

- TDD：新功能测试先失败；页面跳转和提交前目标变化也先复现失败，再补校验。
- npm run verify：15 个测试文件、134 项测试通过，类型检查及 Chrome 生产构建通过。
- npm run build:firefox、npm run zip、npm run format:check 通过。
- Chrome 已登录页面中核对原生帖文菜单与确认界面，随后取消；未提交真实账号拉黑。
- 合成页面验证原生提交、目标不一致、内容复用、导航、取消、超时及并行操作。全部测试使用虚构账号和内容。
- 本地浏览器验证提示条、本地拉黑及设置联动、通配符保存后立即折叠对应作者内容。390 px 与 300 px 宽提示条无横向溢出；桌面设置界面已检查。
- 独立检查发现并修复跨标签页名单覆盖及并发数量边界问题：保存只写未提交的编辑字段；黑名单按账号独立存储，不使用会导致并发后无法读取的数量校验。其他规则列表仍限制 500 项。
- 两处修复经独立复查确认解决，对应两个测试文件共 8 项测试通过。

## 实测边界

X 原生操作的真实提交和服务端成功结果尚未实测。界面仅显示已提交，最终结果以 X 自身反馈为准；页面结构或语言不匹配时会停止并提示使用原生菜单。Firefox 仅验证构建，完整移动端设置页未实测。

权限与版本保持不变。更新后需重新加载扩展并刷新 X 页面。取消本地拉黑或卸载扩展不会撤销 X 黑名单，需要在 X 中取消。
